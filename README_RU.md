# RankForge

Сервис рекомендаций. Он учится на истории действий, находит новые товары и строит личную ленту.

В проекте есть обучение модели, API, веб-интерфейс, база для отзывов и тесты. Все данные в демо созданы программой. Реальных клиентов нет.

## Запуск

Нужен Python 3.11 или 3.12. GPU и ключ API не нужны.

```bash
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install -e '.[dev]'
python -m rankforge.cli serve
```

Откройте http://127.0.0.1:8000. Готовая модель уже есть в папке `artifacts`.

Выберите пользователя. Нажмите Generate feed. Кнопка Save сохраняет выбор. После этого сервис учтёт его в профиле и не покажет этот товар снова. Веса модели при этом не меняются.

Для нового пользователя сервис сначала покажет популярные товары. Группа A видит базовые рекомендации; группа B — результат нейронной модели. Группа зависит от ID пользователя.

## Результат

На тестовых синтетических данных Recall@10 модели — 29,4%, у метода популярных товаров — 4,6%. Простой метод по категориям дал близкий Recall и немного лучший NDCG. Поэтому сложная модель не всегда лучше простой.

Это учебный результат, а не доказательство роста продаж. Полное описание, данные оценки и ограничения — в [README.md](README.md).

```bash
python -m rankforge.cli demo --seed 42 --epochs 30
python -m pytest -q
```
